## 换一个声音出口，少打断一下

耳机、Mac 扬声器、显示器音频，都是日常会用到的声音出口。切换设备时，我希望眼前就有一个入口，点完就能继续手头的事。

所以我做了 AudioSwitch：一个常驻 macOS 菜单栏的小工具，用浮窗显示当前的音频输出设备。

## 展开，选一个设备，继续听

点击浮窗上的箭头，就能展开设备列表；再点一个设备，声音便切换过去。接入或断开音频设备时，列表会自动更新。

浮窗可以拖到顺手的位置，也能显示在不同桌面空间中。不需要时，右键点击菜单栏图标就可以隐藏它。

## 在自己的 Mac 上试试

项目的 GitHub 页面提供安装说明和源码。安装后，先把浮窗放到一个不挡内容的位置，再试着从扬声器切到耳机。

它专注于音频输出设备的切换，适合经常在几种听音设备之间来回切换的人。

## 熟悉的阅读体验，也能留给自己的文档

一份 Markdown 写完后，我希望打开它就能好好读：标题、代码和表格各在其位，界面也足够熟悉。

这就是我做 Refolio 的出发点。它是一个 Chrome 扩展，给本地 Markdown 套上 Codex、Claude、Cursor 或 Kimi 风格的阅读皮肤。文件继续留在原来的位置，不用迁移笔记，也不用注册账号。

## 同一份内容，换一种读法

四种阅读风格可以随时切换，也支持浅色、深色和跟随系统。上面的截图，就是同一篇文档在 Codex 和 Cursor 风格下的样子。

阅读页顶部可以切换皮肤、打开另一份文件，也能从文件名菜单找回最近读过的文档。我想让这些操作待在顺手的位置，把更多空间留给内容。

## 打开你的第一份 Markdown

安装后，点击扩展图标，选择「打开文件」，选一份 `.md` 文档就能开始读。

如果你更习惯把文件直接拖进 Chrome，需要先在扩展的详情页开启「允许访问文件网址」。通过文件选择器打开的文档，如果引用了旁边文件夹里的图片，再按提示授权图片所在文件夹即可。
